# Contributing to the Training Handbook

1. Create a branch from the current `main`.
2. Keep the welcome message nonempty.
3. Run `npm.cmd test` and `npm.cmd run validate`.
4. Push your branch and open a pull request targeting `main`.
5. Obtain an independent approval and a passing `validate-handbook` check.
6. The authorized presenter chooses the merge method during the demonstration.

Use a short, descriptive PR title and link the issue explaining the change.

Do not bypass rules, force-push shared history, move published tags, or add secrets.
Failing validation in the labeled failing-check branch is intentional.
